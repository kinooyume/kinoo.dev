A clone of the **ARTE** catalogue wearing **Netflix**'s design system. ARTE's API was **reverse-engineered**: every page, section and piece of content is generated dynamically from the API data, following the structure of the original site.

The site mirrors arte.tv's routing, so swapping the domain in the URL lands on the same content. Fully **API-first** architecture, close to a **headless CMS**.
